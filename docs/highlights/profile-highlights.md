# GitHub Profile Highlights Guide

Profile Highlights are status badges displayed directly below your user bio on GitHub. Unlike contribution-based achievements, highlights represent account tiers, official program memberships, and security contributions.

## Detailed Requirement Breakdown

### 1. GitHub Pro
- **Who Qualifies:**
  - Individual users who subscribe to GitHub Pro ($4/month).
  - Enrolled students verified with an `.edu` email address or school ID via the **GitHub Student Developer Pack**.
- **Display:** Appears automatically once your subscription or student status is active.

### 2. Developer Program Member
- **Who Qualifies:**
  - Any developer who builds tools, apps, GitHub Actions, or integrations using the GitHub API.
- **How to Apply:**
  - Visit the GitHub Developer Program portal.
  - Submit your application specifying your integration or public GitHub app.
  - Approval is typically granted to established GitHub accounts with active public repositories.

### 3. Security Advisory Credit
- **Who Qualifies:**
  - Researchers and maintainers who discover and responsibly disclose vulnerabilities in open-source packages.
- **How to Earn:**
  - Create a Security Advisory in a repository under **Security** > **Advisories** > **New draft security advisory**.
  - Request a CVE from GitHub.
  - When the advisory is published to the global GitHub Advisory Database, credit is attached to your username.

### 4. GitHub Campus Expert
- **Who Qualifies:**
  - Higher education students who lead technical communities on campus.
- **Application Process:**
  - Applications open in biannual cycles (typically February and August).
  - Selected applicants complete multi-week community building training.

### 5. Security Bug Bounty Hunter
- **Who Qualifies:**
  - Security researchers who discover security flaws in GitHub's own infrastructure, applications, or API.
- **How to Participate:**
  - Submit vulnerability reports through HackerOne on the [GitHub Security Bug Bounty page](https://bounty.github.com/).
  - The badge is awarded once a finding is validated and triaged by GitHub Security.
